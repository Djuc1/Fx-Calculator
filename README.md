## Currency Converter

	Choose two countries to see the conversion rate for a given sum

## Project Specifications

- UI with 2 dropdown menus and number fields for Country & currency values
- Retrieve live exchange data from the API (https://api.exchangerate-api.com)
- Show the converted amounts for each selected currency
- Recalculate conversions when either amount is adjusted
- Enable switching between the two currencies with a swap function
